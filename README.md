# 📖 About

**RescrapX** is a next-generation digital marketplace that connects vehicle owners with authorized **Registered Vehicle Scrapping Facilities (RVSFs)** through a transparent auction-based platform.

The platform simplifies the complete vehicle scrapping process by providing:

- Instant vehicle valuation
- Verified RVSF bidding
- Pickup scheduling
- Real-time tracking
- Government compliant documentation
- Secure payment settlement

Our goal is to eliminate the traditional unorganized scrapping process and create a transparent, secure, and digital ecosystem for vehicle recycling.
